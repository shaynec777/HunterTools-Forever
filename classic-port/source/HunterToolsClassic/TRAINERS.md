# Trainer finder — Classic Era

Open Finders > Trainers or `/ht trainers`. Choose Hunter trainers or Pet trainers, select a row or Mark nearest trainer. Red map/minimap markers clear when speaking to the selected NPC. Native red X marking requires an explicit in-range click. See VENDOR-MARKERS.md for marking and clearing details.

The Classic Era catalog independently bundles 41 trainer references from Wowhead NPC map pins. These are approximate positions, not a claim of complete coverage. Other game editions' coordinates are not used. No external addon dependency. Starter-only trainers are excluded above level 6. Source receipts: classic-port/trainer-classic-source.json in the repository.
